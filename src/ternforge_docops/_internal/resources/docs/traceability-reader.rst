Traceability reader
===================

Read the specification as a normal document. A numbered staircase keeps each
``Goal → Capability → Requirement → Technical requirement`` visible once,
with implementation and verification kept inside the contract they prove instead
of becoming terminal graph nodes. Use the collapsible Goal/Capability sidebar to
jump across the document; machine IDs and concrete test records remain secondary.
